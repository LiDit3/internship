# Задание 9: Windows — Планировщик заданий + BAT-скрипт

## Цель
Создать `.bat`-файл, который выводит `Hello World` с текущим временем, и настроить его **ежедневное выполнение** через Планировщик заданий Windows.

## Стек и инструменты
- **OC:** Windows 10/11
- **Автоматизация:** Bash, BAT, PowerShell, schtasks

##  Часть 1: Создание BAT-файла

### Вариант 1: Простой (вывод в консоль)
```bat
@echo off
:: hello_world.bat
echo Hello World: %TIME%
pause
```
### Вариант 2: С записью в лог-файл (рекомендуется для задач по расписанию)
```bat
@echo off
:: hello_world.bat
set "LOGFILE=C:\Tasks\hello_world.log"

:: Создаём директорию для лога, если нет
if not exist "C:\Tasks" mkdir C:\Tasks

:: Записываем строку с датой и временем в лог
echo Hello World: %DATE% %TIME% >> "%LOGFILE%"

:: Опционально: очищаем лог, если он больше 1000 строк (чтобы не разрастался)
for /f "skip=1000 delims=" %%A in ('type "%LOGFILE%"') do @echo %%A >> "%LOGFILE%.tmp"
if exist "%LOGFILE%.tmp" move /y "%LOGFILE%.tmp" "%LOGFILE%"
```

### Вариант 3: Продвинутый (форматированное время + код выхода)
```bat
@echo off
:: hello_world.bat — расширенная версия
set "LOGFILE=C:\Tasks\hello_world.log"
if not exist "C:\Tasks" mkdir C:\Tasks

:: Получаем отформатированную дату и время (универсально для RU/EN Windows)
for /f "tokens=2 delims==" %%a in ('wmic OS Get localdatetime /value') do set "dt=%%a"
set "YYYY=%dt:~0,4%"
set "MM=%dt:~4,2%"
set "DD=%dt:~6,2%"
set "HH=%dt:~8,2%"
set "Min=%dt:~10,2%"
set "Sec=%dt:~12,2%"

set "TIMESTAMP=%YYYY%-%MM%-%DD% %HH%:%Min%:%Sec%"

:: Запись в лог
echo [%TIMESTAMP%] Hello World >> "%LOGFILE%"

:: Выход с кодом 0 (успех) — важно для Планировщика
exit /b 0
```

> **Совет**: Сохраните файл с кодировкой **ANSI** (не UTF-8), чтобы избежать проблем с кириллицей в консоли.

## Часть 2: Настройка в Планировщике заданий

### Способ 1: Через графический интерфейс (GUI)

1. **Откройте Планировщик**:
   - `Win + R` → введите `taskschd.msc` → Enter
   - Или: Пуск → "Планировщик заданий"

2. **Создайте задачу**:
   - В правой панели → **"Создать простую задачу..."**
   - Или: Правой кнопкой на "Библиотека планировщика" → **"Создать задачу..."** (расширенные настройки)

3. **Мастер настройки**:
   | Шаг | Значение |
   |-----|----------|
   | **Имя** | `Hello World Daily` |
   | **Триггер** | Ежедневно, время: например, `09:00` |
   | **Действие** | "Запустить программу" |
   | **Программа** | `C:\Tasks\hello_world.bat` (укажите полный путь!) |
   | **Начальная папка** | `C:\Tasks\` (важно для корректной работы относительных путей) |

4. **Дополнительные настройки** (вкладка "Условия" и "Параметры"):
   - "Запускать только при питании от электросети" (для ноутбуков)
   - "Запускать с наивысшими правами" (если скрипт требует админ-доступ)
   - "Не останавливать, если выполняется дольше..." (по умолчанию 72 часа)
   - "Включить задачу немедленно" (для теста)

5. **Завершите мастер** → задача появится в библиотеке.

### Способ 2: Через командную строку (schtasks) — для автоматизации

```cmd
:: Создаём директорию и скрипт (выполнять в CMD от имени администратора)
mkdir C:\Tasks
notepad C:\Tasks\hello_world.bat
:: ...вставьте содержимое скрипта и сохраните...

:: Создаём задачу на ежедневное выполнение в 09:00
schtasks /create ^
  /tn "Hello World Daily" ^
  /tr "C:\Tasks\hello_world.bat" ^
  /sc daily ^
  /st 09:00 ^
  /ru SYSTEM ^
  /rl HIGHEST ^
  /f

:: Проверка создания
schtasks /query /tn "Hello World Daily"

:: Запуск вручную для теста
schtasks /run /tn "Hello World Daily"

:: Просмотр истории выполнения (события 100/102/201)
Get-ScheduledTask -TaskName "Hello World Daily" | Get-ScheduledTaskInfo
```

> `/ru SYSTEM` — запуск от имени системы (не требует пароля).  
> `/ru "USERNAME"` — запуск от имени пользователя (потребуется указать пароль через `/rp`).

## Проверка выполнения

### 1. Просмотр логов
```cmd
type C:\Tasks\hello_world.log
```
Ожидаемый вывод:
```
[2026-05-20 09:00:01] Hello World
[2026-06-20 09:00:03] Hello World
```

### 2. История в Планировщике
- Откройте задачу → вкладка **"Журнал"**
- Или в PowerShell:
  ```powershell
  Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-TaskScheduler/Operational'; TaskName='Hello World Daily'} -MaxEvents 5
  ```

### 3. Быстрый тест вручную
```cmd
C:\Tasks\hello_world.bat
```
→ Должно отобразиться: `Hello World: 14:25:33,45` (или аналогично).

## Отладка и частые проблемы

| Проблема | Решение |
|----------|---------|
| Задача не запускается | Проверьте: полный путь к `.bat`, права пользователя, галочку "Запускать с наивысшими правами" |
| Скрипт выполняется, но лог пустой | Убедитесь, что используется `>>` (добавление), а не `>` (перезапись); проверьте права на запись в `C:\Tasks\` |
| Кракозябры в логе | Сохраните `.bat` в кодировке **ANSI** (Блокнот → "Сохранить как" → Кодировка: ANSI) |
| Не работает `%TIME%` в логе | В некоторых локалях `%TIME%` содержит пробелы — используйте кавычки: `echo "Time: %TIME%"` |
| Задача висит в статусе "Готово", но не запускается | Проверьте вкладку "Условия": снимите "Запускать только при питании от сети" для теста |

## Безопасность и лучшие практики

1. **Не храните пароли в скриптах** — используйте `/ru SYSTEM` или управляемые учётные записи.
2. **Ограничьте права**: если скрипт не требует админ-доступа, не ставьте "Запускать с наивысшими правами".
3. **Ротация логов**: добавьте очистку старых записей, чтобы лог-файл не занимал весь диск.
4. **Тестируйте вручную** перед запуском по расписанию.
5. **Документируйте**: добавьте комментарий в начало `.bat`:
   ```bat
   :: Задача: ежедневный лог "Hello World"
   :: Автор: ВашеИмя
   :: Дата создания: 20.05.2026
   ```

## Бонус: Мониторинг выполнения через PowerShell

Создайте скрипт `check_task.ps1` для быстрой проверки:
```powershell
# check_task.ps1
$task = Get-ScheduledTask -TaskName "Hello World Daily" -ErrorAction SilentlyContinue
if ($task) {
    $info = $task | Get-ScheduledTaskInfo
    Write-Host "Задача найдена" -ForegroundColor Green
    Write-Host "Последний запуск: $($info.LastRunTime)"
    Write-Host "Результат: $($info.LastTaskResult)"
    Write-Host "`n📄 Последние 5 строк лога:"
    Get-Content C:\Tasks\hello_world.log -Tail 5 -ErrorAction SilentlyContinue
} else {
    Write-Host "Задача не найдена" -ForegroundColor Red
}
```

Запуск:
```powershell
powershell -ExecutionPolicy Bypass -File C:\Tasks\check_task.ps1
```
