# Задание 1: Развёртывание виртуальных машин и настройка сетевого доступа

## Цель
Освоить базовые навыки виртуализации, установки гостевых ОС и конфигурации сетевых подключений. Подготовить изолированное тестовое окружение для последующих задач стажировки и зафиксировать процесс в портфолио.

## Стек и инструменты
- **Гипервизор:** `Oracle VM VirtualBox` (выбран из предложенного списка: VirtualBox, VMware Player/Workstation, QEMU, DOSBox)
- **Гостевые ОС:** 
  - Windows (любая доступная редакция, например Win10/Win11)
  - Linux (любой дистрибутив, **режим минимальной установки** без графического окружения)
- **Сеть:** NAT / Bridged Adapter / Настройка прокси (при необходимости)

## Чек-лист выполнения
- [ ] Установлен и запущен VirtualBox
- [ ] Создана ВМ #1: Windows, установлена ОС, выполнены первичные обновления
- [ ] Создана ВМ #2: Linux, выполнена **минимальная установка** (только ядро, базовые утилиты, без GUI)
- [ ] Настроен сетевой адаптер для обеих ВМ (рекомендуется `NAT` или `Сетевой мост`)
- [ ] Проверен доступ в интернет
- [ ] При отсутствии доступа: диагностирована причина, настроен прокси или скорректированы параметры сети
- [ ] Зафиксированы ключевые шаги, конфигурации и решения проблем

## Проверка результата (Success Criteria)
| ОС | Команда / Действие | Ожидаемый результат |
|----|-------------------|---------------------|
| Windows | Открыть браузер → перейти на `ya.ru` | Страница загружается без ошибок |
| Linux | `curl -I ya.ru` или `wget -qO- ya.ru` | HTTP `200 OK` и содержимое главной страницы |

> Если сайт не открывается: проверьте DNS (`nslookup ya.ru`), настройки прокси в ОС и тип сетевого адаптера VirtualBox. При корпоративном прокси укажите его в системных настройках или через переменные `HTTP_PROXY` / `HTTPS_PROXY`.
